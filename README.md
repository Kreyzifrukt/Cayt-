# ORBIT — Personal Command Center

A polished, local-first productivity workspace built with React, TypeScript and Vite.

## Features
- Task board with priorities, filters and quick actions
- Focus timer with session tracking
- Notes with search and autosave
- Habit tracker and weekly activity overview
- Persistent settings and theme selection
- Responsive layout and keyboard-friendly controls

## Development

```bash
npm install
npm run dev
```

## Production

```bash
npm run build
npm run preview
```

All user data is stored locally in the browser. No account or backend is required.
